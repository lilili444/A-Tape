# MyJournal（项目名待定）

只给自己用的个人管理网页，手机和电脑打开同一个网址就能用。数据存在自己的 Supabase 里，登录后才能看到。

- 网址：<https://lilili444.github.io/MyJournal/>
- 板块：**手记**（日记，已完成）· **纪念日 / 倒数日**（筹备中，数据会放在同一个项目里）
- 视觉：极简纸面风

---

## 手记的功能

| 模块 | 说明 |
|---|---|
| 日历 | 侧栏顶部的小日历，有日记的日子下面有小圆点。在时间线里点某一天就只看那一天，再点一次取消；在三年/五年日记里点某一天就跳到那一天 |
| 视图 | **时间线**：按月份分组，最新的在最上面；**三年日记 / 五年日记**：把往年同一天的日记叠在一页，可以前后翻天、选日期、补写 |
| 日记本 | 可以自己新建、改名、删除；每篇日记属于一个日记本。新日记默认放进最近一篇日记所在的日记本 |
| 标签 | 一篇可以打多个标签，输入时会自动提示，回车或逗号添加；侧栏可以按标签筛选、改名、删除 |
| 写日记 | 标题可写可不写；可以改日期时间、选日记本；照片（自动压缩到长边 1600px）；录音（单个最多 50MB）；链接卡片（歌、电影、文章……）；收藏；关闭时自动保存 |
| 搜索 | 正文、标题、标签、链接都能搜。日记本、标签、搜索三种筛选可以叠加 |
| 统计 | 侧栏显示摘要，点开是完整统计页：当前/最长连续天数、当前/最长每周连续、按年份的每月篇数柱状图、写日记的天数、字数、照片、录音、链接 |
| 备份 | 导出成一个 `.json` 文件（包含照片和录音），也可以导入 |
| 快捷键 | `N` 写新日记 · `⌘K` 搜索 · `Esc` 或 `⌘↵` 完成 · 三年/五年日记里 `←` `→` 翻天 |

**手机版**：顶部一排小按钮：视图、日记本、标签、搜索、统计、备份。点开才展开对应面板，平时一打开就是日记内容。右下角的“写”按钮用来写新日记。“视图”面板里包括日历。

## 文件结构

```
MyJournal/
├── index.html           页面骨架：侧栏、手机顶部栏、主区、登录页
├── style.css            全部视觉：颜色、字体、间距、版式（自己装修主要改这里）
├── app.js               全部功能：读写数据、日历、视图、统计、编辑器、登录
├── config.js            Supabase 的网址和 Publishable key（可以公开）
├── supabase/
│   └── schema.sql       建表、权限规则、照片和录音的存储空间（可以重复运行）
└── README.md            就是这份说明
```

**数据放在哪里**

| 地方 | 放什么 | 是否公开 |
|---|---|---|
| 这个 GitHub 仓库 | 只有程序代码 | 公开（GitHub Pages 免费版要求公开） |
| Supabase · `records` 表 | 日记、标签、日记本，以后还有纪念日。每条一行，内容是 JSON | 私有，只有登录的本人能读写 |
| Supabase · `photos` 存储桶 | 照片，路径是 `用户ID/照片ID.jpg` | 私有 |
| Supabase · `media` 存储桶 | 录音，路径是 `用户ID/文件ID` | 私有 |

`app.js` 最上面的 `Store` 是唯一和 Supabase 打交道的地方。以后要换存储方式，只需要改这一块。

### 自己改视觉

- **先改 `style.css` 最上面的 `:root`**：`--paper`（页面底色）、`--sheet`（编辑纸和面板）、`--ink`（文字）、`--ink-soft`（次要文字）、`--rule`（细线）、`--accent`（选中、收藏、今天）、`--font-display` / `--font-body`（字体）。改这几个变量，全站会一起变。
- 想换字体：在 `index.html` 的 Google Fonts 链接里换字体名，再改 `--font-display` / `--font-body`。
- 各部分对应的样式：板块切换 `.sections`、日历 `.cal-*`、侧栏 `.side`、时间线 `.entry`、月份标题 `.month`、三年/五年日记 `.yrow`、统计页 `.st-*` 和 `.chart`、编辑纸 `.sheet`、录音 `.audio-item`、链接卡片 `.link-card`、手机顶部栏 `.mbar`、手机面板 `.mpanel`、写日记按钮 `.fab`。
- 手机版的样式都在 `style.css` 底部的 `@media (max-width: 760px)` 里。
- 只改 `style.css` 不会影响数据和功能。上传后如果没变化，按 `⌘⇧R` 强制刷新。

### 改项目名

浏览器标签页的名字在 `index.html` 的 `<title>`，登录页的大标题在 `index.html` 里 `class="login-sheet"` 下面的 `<h1>`，改这两处就行，数据库不用动。改 GitHub 仓库名会改变网址。

## 第一次设置（只做一次）

1. **建数据库**：Supabase 后台 → **SQL Editor** → New query → 粘贴 `supabase/schema.sql` 的全部内容 → **Run**。以后这个文件有更新，就再运行一次，不会删掉已有数据。
2. **建自己的账号**：**Authentication → Users → Add user → Create new user**，填邮箱和密码，勾选 **Auto Confirm User**。这是登录这个网站用的账号。
3. **关闭注册**：**Authentication → Sign In / Providers** → 关掉 **Allow new users to sign up**。
4. **打开 GitHub Pages**：仓库 **Settings → Pages** → **Deploy from a branch**，选 **main**、**/ (root)** → Save。

## 日常使用

- **更新代码**：在 GitHub 网页上打开文件 → 铅笔图标编辑；或者 **Add file → Upload files** 上传新版本覆盖 → Commit。1～3 分钟后网站自动更新。
- **导入以前的日记**：点“导入备份”，选 `.json` 文件。同一篇日记不会重复。
- **Supabase 暂停**：免费项目一周没有任何访问会被暂停。数据不会丢，在后台点 **Resume project** 就能恢复。

### 从苹果手记搬过来的日记

2026-11-22 从苹果手记导入了 319 篇日记，按日期分进三个日记本：本科（2024-01-14 – 2025-04-10）、Gap（其余日期）、英国（2026-09-17 – 2026-11-22）。

- 苹果手记的导出文件里只有日期、没有具体时间，所以同一天的几篇按原来的先后顺序排，时间从 12:00 开始。
- 苹果手记的导出文件里没有 Journal 信息，所以标签需要手动加。
- 照片统一压缩到长边 1600px；录音作为附件导入；视频没有导入；音乐、心情、运动记录写成了日记末尾的“【手记附件】”文字说明。
- 每篇导入的日记有 `source: "apple-journal"` 和原文件名 `sourceFile`，以后需要时可以对回原始导出。

## 备份（请定期做）

Supabase 免费版**没有自动备份**。误删或改错的数据，云端没办法帮你找回。

1. **手动备份**：每隔一两周点一次“导出备份”，把 `.json` 文件存到电脑或 iCloud。
2. **自动备份**（计划中）：用 GitHub Actions 每周把数据导出到另一个**私有**仓库。

## 安全

- `config.js` 里的 **Publishable key**（`sb_publishable_…`）本来就是给网页用的，放在公开仓库里没问题。数据安全靠 `schema.sql` 里的权限规则（Row Level Security）：没登录什么都读不到，登录了也只能读写自己的数据。
- **Secret key（`sb_secret_…`）、旧版的 service_role key、数据库密码**：绝对不能出现在这个仓库的任何文件里，也不要发给任何人。万一泄露，去 Supabase 后台 **Settings → API Keys** 换一把新的。
- 这个仓库是公开的，**不要**把日记内容或备份文件上传到这里。
